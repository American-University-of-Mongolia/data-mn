# mongolbank-credit-private-sector v1

## Version Notes

- **Created**: 2026-03-09
- **Data range**: 2004-01 to 2026-01 (265 monthly records)
- **Source**: stat.mongolbank.mn API, Report ID 90, Indicator ID 60870
- **Unit**: Billion MNT (converted from million MNT raw API values)
- **Series**: Outstanding credit to the private sector from depository corporations survey

## Files

- `data-en.csv` - English CSV (date, credit_billion_mnt)
- `data-mn.csv` - Mongolian CSV (огноо, зээл_тэрбум_төгрөг)
- `data.xlsx` - Wide-format Excel (months as rows, years as columns; two sheets EN/MN)
- `chart-en.json` - Vega-Lite chart spec (English)
- `chart-mn.json` - Vega-Lite chart spec (Mongolian)

## Key Stats

- First date: 2004-01 (249.88 billion MNT)
- Last date: 2026-01 (17,121.49 billion MNT)
- Growth: ~68x over 22 years
