# GDP Growth Rate - Version History

## Dataset Type: SPLIT

This is a **split dataset** derived from the parent dataset `nso-gdp-by-economic-activity`.

## Data Storage

**Split datasets do NOT store raw source data in their version directories.**

Instead, this dataset is generated by:
1. Reading the parent's data from `tools/versions/nso-gdp-by-economic-activity/v{N}/`
2. Applying the split filter: `{"Indicator": "Annual changes, by percent", "Economic activity": "Total"}`
3. Generating the filtered CSV and chart files

## Parent Dataset

- **Parent ID**: `nso-gdp-by-economic-activity`
- **Parent Source**: NSO Table `DT_NSO_0500_001V1.px`
- **Parent Version Directory**: `tools/versions/nso-gdp-by-economic-activity/`

## Version History

### v1 (Initial)
- Created: 2025-12-03
- Source: Parent dataset v1
- Records: 34 years (1991-2024)
- Filter Applied: Indicator="Annual changes, by percent", Economic activity="Total"

## Update Process

When the parent dataset is updated:
1. Parent fetches new data from NSO 1212.mn API
2. Parent saves to `nso-gdp-by-economic-activity/v{N}/`
3. Split regeneration applies filter to create this dataset
4. Output files saved to `data.mn/public/datasets/gdp-growth-rate-*.csv`

## Files Generated

This split produces:
- `data.mn/public/datasets/gdp-growth-rate-en.csv` (chart data)
- `data.mn/public/datasets/gdp-growth-rate-mn.csv` (chart data)
- `data.mn/public/charts/gdp-growth-rate-en.json` (Vega-Lite spec)
- `data.mn/public/charts/gdp-growth-rate-mn.json` (Vega-Lite spec)
- `data.mn/src/data/data/en/gdp-growth-rate.mdx` (English page)
- `data.mn/src/data/data/mn/gdp-growth-rate.mdx` (Mongolian page)

## Notes

- This directory structure exists for consistency with the registry expectations
- Raw data is NOT duplicated here - always refer to parent's version directory
- To update this dataset, update the parent: `python -m registry info nso-gdp-by-economic-activity`
