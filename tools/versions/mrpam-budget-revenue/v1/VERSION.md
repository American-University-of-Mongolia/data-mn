# MRPAM Budget Revenue — Version 1

- Dataset: `mrpam-budget-revenue`
- Data period: January 2021 through June 2026
- Data as of: 2026-06-30
- Source: MRPAM monthly statistical reports, Tables 5.1 / 6.1
- Unit: million MNT
- Full-data rows: 420
- Chart rows: 66 total-revenue observations

All 66 reports in the canonical 2021–2026 manifest were checked. Reports from
2021 and early 2022 identify the budget table as 6.1, while later reports use
5.1. Values are cumulative within each report year. Source-null actual and
percentage cells remain empty.

The English download translates every revenue category. The Mongolian download
preserves the source labels, and numeric values match between languages.
