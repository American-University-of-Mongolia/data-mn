# Version 1

- Materialized the first data.mn release from 69 staged MRPAM monthly reports.
- Added all 66 monthly observations from January 2021 through June 2026.
- Standardized the source measures as production, sales, and exports in thousand
  tonnes.
- Recovered eight monthly rows from later same-year historical tables when
  their individual reports did not yield a reliable row; no values were
  estimated.
- Added bilingual CSV downloads, an Excel workbook, bilingual charts, and
  bilingual data pages.
