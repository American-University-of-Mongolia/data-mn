## Description

Crude Birth Rate (CBR) is the number of live births per 1,000 population per year. This split extracts the CBR row from the parent dataset's multi-dimensional birth rate data.

## Key Statistics

- **1980**: 39.2 per 1,000
- **2024**: 16.9 per 1,000
- **Decline**: 57% over 44 years
