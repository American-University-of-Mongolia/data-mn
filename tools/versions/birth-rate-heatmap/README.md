# Birth Rate Heatmap - Version History

## Dataset Type: SPLIT

This is a **split dataset** derived from the parent dataset `nso-birth-rates-by-age`.

## Data Storage

**Split datasets do NOT store raw source data in their version directories.**

Instead, this dataset is generated by:
1. Reading the parent's data from `tools/versions/nso-birth-rates-by-age/v{N}/`
2. Applying the split filter: `{"age_group": ["15-19", "20-24", "25-29", "30-34", "35-39", "40-44", "45-49"]}`
3. Generating the filtered CSV and heatmap chart files

## Parent Dataset

- **Parent ID**: `nso-birth-rates-by-age`
- **Parent Source**: NSO Table `DT_NSO_0300_029V1.px`
- **Parent Version Directory**: `tools/versions/nso-birth-rates-by-age/`
- **Parent Definition**: `tools/sources/nso-1212/datasets/nso-birth-rates-by-age.md`

## Update Process

When the parent dataset is updated:
1. Parent fetches new data from NSO 1212.mn API
2. Parent saves to `nso-birth-rates-by-age/v{N}/`
3. Split regeneration applies filter to create this dataset
4. Output files saved to `data.mn/public/datasets/birth-rate-heatmap-*.csv`
