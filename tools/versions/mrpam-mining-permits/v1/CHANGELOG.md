# Version 1

- Materialized the first complete data.mn release from 66 staged MRPAM
  monthly reports.
- Added 1,452 province-month observations from January 2021 through June 2026,
  covering all 21 aimags and Ulaanbaatar.
- Preserved licensed-area values in the source unit of thousand hectares.
- Excluded totals, blank rows, and non-province text from the full downloads.
- Added bilingual full CSV downloads, a bilingual Excel workbook, national
  permit-count charts, and bilingual data pages.
