# Mongolia Poverty Rate - Version History

## Dataset Type: SPLIT

This is a **split dataset** derived from the parent dataset `nso-poverty-indicators`.

## Data Storage

**Split datasets do NOT store raw source data in their version directories.**

Instead, this dataset is generated by:
1. Reading the parent's data from `tools/versions/nso-poverty-indicators/v{N}/`
2. Applying the split filter: `{"Indicator": "Poverty Headcount", "Location": "National average"}`
3. Generating the filtered CSV and chart files

## Parent Dataset

- **Parent ID**: `nso-poverty-indicators`
- **Parent Source**: NSO Table `DT_NSO_1900_007V1.px`
- **Parent Version Directory**: `tools/versions/nso-poverty-indicators/`
- **Parent Definition**: `tools/sources/nso-1212/datasets/poverty-rate-national.md`

## Version History

### v1 (Initial)
- Created: 2026-02-27
- Source: NSO Table DT_NSO_1900_007V1.px
- Records: 12 survey years (1995-2020)
- Filter Applied: Indicator="Poverty Headcount", Location="National average"

## Update Process

When the parent dataset is updated:
1. Parent fetches new data from NSO 1212.mn API
2. Parent saves to `nso-poverty-indicators/v{N}/`
3. Split regeneration applies filter to create this dataset
4. Output files saved to `data.mn/public/datasets/poverty-rate-national-*.csv`

This split produces:
