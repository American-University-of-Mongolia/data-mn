# Tourism Arrivals to Mongolia - Version 1

**Dataset ID**: `inbound-passengers-tourism`
**Version**: 1
**Created**: 2026-01-29
**Type**: Split dataset (child of `nso-inbound-passengers-by-region-purpose`)

## Overview

Tourism arrivals to Mongolia from 2006 to 2025, showing visitors whose primary purpose is tourism (excluding business, work, study, and other purposes).

## Filter Applied

- **Region**: Total (all regions)
- **Purpose**: Tourism only

## Data Summary

- **Rows**: 20
- **Years**: 2006-2025
- **Range**: 1,010 (2021) to 417,935 (2025)

## Files

- `data-en.csv` - English version
- `data-mn.csv` - Mongolian version

## Key Insights

- **Pre-pandemic peak**: 260,078 in 2019
- **COVID-19 impact**: Collapsed to 7,798 (2020) and 1,010 (2021)
- **Strong recovery**: 417,935 in 2025 (61% above pre-pandemic)

## Source

National Statistics Office of Mongolia (1212.mn)
