# Infant Mortality National - Version 1

## Dataset Information

- **Dataset ID**: infant-mortality-national
- **Version**: 1
- **Source**: NSO 1212.mn (DT_NSO_2001_014V1.px)
- **Created**: 2026-01-29

## Description

National infant mortality rate per 1,000 live births from 2000-2024.

## Data Files

- `data-en.csv` - English version
- `data-mn.csv` - Mongolian version

## Output Files

- `data.mn/public/datasets/infant-mortality-national-en.csv`
- `data.mn/public/datasets/infant-mortality-national-mn.csv`
- `data.mn/public/datasets/infant-mortality-national.xlsx`

## Notes

Data shows significant improvement in infant mortality over the 24-year period.
